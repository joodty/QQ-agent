QQ Agent使用帮助

从一个聊天开始

人设决定机器人怎么说话，档案保留这次人设的对话，费用按群或私聊一起计算。切换档案不会重置当天花费。

开始使用人设与档案费用与权限数据模型进入工作台

开始使用

  1. 注册并登录，从右上角账号菜单进入“账号设置”，验证本人 QQ。
  2. 与公用机器人私聊时，可按平台授权使用体验额度。想使用自己的模型，在“我的 API 配置”保存自己的 Key。
  3. 管理群聊时，先把公用机器人加入群，再验证你的群主或管理员身份。同一个群可有多位管理者，当前档案和预算仍共用一份。
  4. 进入“我的聊天”，选择群或私聊，在“人设与会话”保存并应用人设。每个聊天内还可独立查看概览、语音设置、费用与额度、聊天记录。

聊天设置与平台设置

“聊天工作台”先选聊天再设置，页面标注“仅影响当前聊天”。“沿用平台默认”表示该项随平台默认值变化；独立覆盖只对当前群或私聊生效。

管理员的“平台管理”页面标注“影响整个平台”。平台模型与“我的 API 配置”分别管理平台出资与个人提供的服务；更换模型和费用来源不产生另一套聊天能力。账号设置、帮助与退出登录都在右上角账号菜单。

人设、档案和运行记录

名称用途
人设版本角色名字和提示词。保存新版本不会改变当前聊天。
人设档案某个聊天使用一个人设版本时的历史和记忆。明确应用时创建并选择档案；之后可切回原档案继续。
运行记录机器人一次处理消息的过程，包含模型调用与工具结果。它不是群的全部聊天历史。

旧版本与旧档案会保留。保留对话历史不等于保证模型供应商缓存永久命中。

费用与权限

一个群的所有人设共用每日额度；私聊也有限额。已经花费、在途请求和费用未知的调用都会占额。接近 80% 时减少参与和输出，额度不足时停止新的付费请求。

自己的 Key 只用于明确选择它的聊天。Key 失效或费用归属不明确时会停止调用，不会改用平台 Key。普通账号管理获授权群和本人私聊；管理员通过顶部“平台管理”进入平台模型、平台语音、费用规则、账号授权和高级控制台；聊天工作台与普通账号使用相同功能。

金额是估算值，以供应商账单为准。退出登录、切换人设和重启服务不会退回花费。

公开设计与开发交接文档

手动发消息与群发

在“我的聊天”选择群或私聊，再进入“聊天记录”，可以通过机器人QQ发送文字或语音，并查看成功发送的历史。手动文字不调用AI或语音服务；选择语音则编辑要朗读的文字，指定本条音色，先免费核算再确认合成发送。需要当前聊天管理权限，且机器人名单和发送频率允许。

管理员还可在“平台管理 → 群发消息”勾选群聊或私聊，核对预览后发送。默认不选中任何对象，每批最多20个目标、文字最多2000字符。语音每个目标独立核算、合成和计费，正文受各聊天单句上限约束（最多150字符）。指定音色只影响这条消息，不修改默认设置，也不按自动回复概率抽样。需要聊天已开启语音、语音资助及可用费用来源；核算只检查条件，不收费、不发送。逐项查看合成与QQ送达结果；结果待确认时不要重复发送。

语音回复

在“我的聊天”选择群聊或私聊，再进入“语音设置”，点击“选择音色 / 试听”，可按精品、大模型、超自然三类筛选，也可按性别、场景或名称、ID搜索。点击音色卡片，再确认并保存设置才会生效；聊天可以沿用平台默认音色。官方示例仅在点击试听时加载，不发起收费合成。腾讯云免费试听入口在每个卡片上。若当前聊天已经开启语音且额度获授权，也可点击“合成试听”：朗读固定短句并在浏览器播放，不发到 QQ；这会占用当前聊天的语音与总额度，并受冷却限制，按钮显示预计费用。

每个音色显示对应的每万字符标价与资源包类别。不同类别的资源包不能混用，免费包余额与实际抵扣尚未同步，预算仍按标价控制。

每个群或私聊共用一份语音开关、短句上限和冷却时间。管理员另行开通平台语音额度，使用自己的模型 API Key 不会自动获得语音额度。明确要求“用语音回复”时不受概率影响；普通聊天回复按配置的自动语音概率抽样，每次完整回复只抽一次。定时主动问候、提醒和账号通知不自动转语音；未配置腾讯云凭据时保持关闭。费用按标准价格估算，腾讯云免费资源包抵扣尚未同步。

聊天内“语音设置”按日期查看当前聊天用量；“费用总览”汇总自己管理的聊天，平台管理员还可在“平台语音服务”查看全平台语音用量。成功合成不代表 QQ 已送达；旧记录没有保存字符数时会显示不可追溯。费用只统计主账一次，资源包抵扣和腾讯实际账单未同步。
