# 工作台与平台管理

2026-10-23。按管理范围分区，所有账号使用同一套聊天能力，管理员额外拥有平台管理入口。分区不产生第二套账号、机器人或聊天引擎，权限由原服务端逐次核验。

## 页面结构

```
聊天工作台
├─ 我的聊天
│  └─ 指定群聊 / 本人私聊
│     ├─ 概览
│     ├─ 人设与会话
│     ├─ 语音设置
│     ├─ 费用与额度
│     └─ 聊天记录
├─ 费用总览（自己有权管理的聊天）
└─ 我的 API 配置

平台管理（管理员）
├─ 平台概览
├─ 模型与服务
│  ├─ 平台模型配置
│  └─ 平台语音服务
├─ 费用规则
│  ├─ 默认聊天额度与私聊体验额度
│  └─ 语音资助额度
├─ 账号与授权
└─ 高级控制台

右上角账号菜单
├─ 账号设置（QQ 验证、密码、群管理身份验证）
├─ 使用帮助
├─ 浅色 / 深色
└─ 退出登录
```

“我的 API 配置”只维护当前账号提供的凭据；“平台模型配置”维护平台出资的默认模型。普通账号也有完整的聊天人设、档案、语音、费用与历史入口，但不能修改全平台默认值或提升平台补贴。

具体聊天的页面显示“仅影响当前聊天”。未覆盖的音色、概率等明确标注“沿用平台默认”。平台表单显示“影响整个平台”，语音资助表单同时明确目标聊天，防止把群设置误当平台设置。

## 路由与兼容

新列表入口为 `#workbench`。聊天详情使用 `#chat/<encodeURIComponent(chatKey)>/<overview|personas|speech|costs|messages>`；`group:` 与 `private:` 保留完整身份。`#cost-overview`、`#keys`、`#account`、`#help` 为共用入口。

平台入口使用 `#admin/<overview|models|speech|budgets|subsidies|accounts|advanced>`。普通账号直接输入平台链接仍不得读取平台数据；隐藏按钮不替代服务端校验。

旧 `#home` 转到列表；旧 `#chats`、`#speech`、`#costs` 在读取当前授权范围后，转到当前或首个有权管理的聊天详情，没有资源则回到列表。旧 `#platform`、`#accounts` 对管理员转到相应平台页面。浏览器前进、后退及直接打开链接使用相同解析路径，不靠“切换视角”决定权限。

## 按需读取

聊天列表只取摘要；人设、历史、语音设置、费用各自进入时读取。平台账号列表、模型配置、语音服务、补贴和高级控制台不随聊天页加载。跨聊天费用页只取当前授权汇总，平台概览单独取全平台汇总；历史成本、模型成本与语音成本按主账归因，资助辅助账不重复加入。

沿用 [性能与缓存边界](WORKSPACE_PERFORMANCE.md)：公共资源内容版本缓存、私有资料短期页面内存缓存、权限/预算新鲜读取、GET 超时可重试、写入和收费试听不自动重试。切群、换账号、撤权和迟到响应必须继续隔离，不能为导航重构退回整站一次性加载。
