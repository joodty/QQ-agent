# 当前聊天的回复概率与语音授权

在“聊天工作台 → 我的聊天”选择群聊或私聊：

- **概览 → 文字回复概率**：决定普通日常消息是否触发AI处理。填0至100整数；留空恢复原有策略。每个群、每个私聊分别保存，不调整其他对象。
- **语音设置 → 自动语音概率**：已经触发回复后，决定适合朗读的完整回复是否使用语音。与日常回复概率分开；明确要求语音时沿用原有规则。
- **语音设置 → 当前聊天语音授权与每日额度**：管理员可直接开通或关闭当前群/私聊的语音资助，设置日额度及允许的模型费用来源，保存后再开启当前聊天语音。普通账号只读这部分授权，可以管理自己有权管理的聊天语音偏好。

语音授权、聊天语音开关、平台语音开关与费用准入都要满足；模型API Key不自动获得腾讯语音额度。关闭资助不会自动重新分配资金，也不会放宽总预算。

回复概率影响普通消息随机触发，不保证每几条必回一条。群内明确召唤、关键词和拍一拍保持原触发规则；显式概率约束活跃期普通消息，定时主动消息仍由原独立策略管理。清除概率覆盖恢复原群滑条/峰谷及私聊默认必回，不清理历史或更换人设。

后端通过统一 `GET/PUT /api/platform/reply-settings` 管理，使用完整 `group:号码/private:号码`；服务器验证当前账号和资源权限，整数百分比及版本CAS防止旧页面覆盖新配置。配置保存在现有私有配置的 `store.replyByChat`，清除时保留递增版本，避免设定—清除—再设定的版本回绕。名称索引不授予管理权。

日常版本使用关键功能与权限测试先发布；累计3～5个版本做较大回归，实际测试与部署记录见工作记录。
