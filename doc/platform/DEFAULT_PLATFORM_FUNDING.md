# 默认平台资助

平台管理员在“平台管理 → 费用规则”开启“自动使用平台额度”，并设置默认每日额度。当前产品约定为每个获准聊天每天0.1元，按北京时间零点换日；已有独立日额继续覆盖默认值。

未单独选择费用来源时，群聊与私聊自动沿用平台Key。资格仅来自当前白名单、有效本人QQ绑定或精确资源授权；仅存在历史、能被管理员查看，或属于其他机器人都不会获得资助。开启总规则无需逐聊天写入资金表，也不创建聊天历史。

显式设置始终优先：用户自己选择的Key保持自己的Key，失效不回退平台；明确暂停或撤销的出资不会被默认开通恢复。群与同号私聊分别记账，同一聊天的所有人设和会话共享额度。权限、报价、预留、并发、80%降级、未知费用和模型/语音总预算仍由原费用链处理。

私聊体验的旧独立授权与语音资助保留各自限制；自动模型资助不意味着自动开通收费语音。后台策略使用 `productionBudget.defaultPlatformFunding`，`defaultFundingVersion` 为服务器维护的代数；浏览器不能自行修改代数。旧配置没有开关时保持关闭，发布时由管理员明确启用。

保存默认规则不会重置当日消费、跨日unknown、独立额度或历史资金记录。若降低上限后已有消费/预留超额，后续调用按新上限停止，不删除旧账。回退应只恢复代码及本次授权的默认策略字段，不能用旧数据库覆盖上线后新消息或费用。
