# 本人 QQ 接入与机器人偏好

2026-10-24：普通账户登录平台后，在“我的机器人”填写本人 QQ，发起接入、扫码并管理自己的 QQ Agent。管理员拥有相同的本人接入功能，另可编辑平台默认偏好。现有公共机器人的聊天工作台和历史数据继续保留。

## 接入与隔离

`/my-bots.html` 使用原有账号 Cookie。账号本人提交申请后，平台保存稳定 owner、预期 QQ、slot、版本和状态，再由只监听回环的 broker 启动独立 SnowLuma 与 QQ Agent 容器。每次操作重查会话和数据库所有权；管理员不能通过新接口接管朋友的申请。后台连接令牌、OneBot 令牌、模型及语音密钥均不返回浏览器。

扫码 QQ 必须等于申请 QQ。成功取得登录信息后才启动 Agent；实例身份接口通过核验且本人偏好应用完成后才报告 ready。错账号停止实例；二维码过期可刷新；停止会保留本人登录与聊天资料。SQL 租约及唯一约束处理重复操作、跨进程并发和不确定清理，未确认停止时不释放容量。

QQ Agent 的 data、HOME、密钥、端口、费用账本和 OS UID 均独立；同一个数字在不同 bot、群和私聊中对应不同资料。共享代码只读挂载。旧 Bridge、DSH 服务继续停用。

实例只接受精简的内部设置接口。平台定期核验账号状态并续发最长两分钟的授权租约；平台不可用或所属账号停用时，授权到期后拒绝新模型调用和 QQ 发出。入站与出站同时验证预期 QQ，切号和断线不沿用旧连接身份。

## 本人可调整的项目

| 设置 | 行为 |
| --- | --- |
| AI 回复总开关 | 暂停或启用本人 AI |
| 仅 @ 回复 | 群聊只接收明确 @ 的召唤；普通概率、关键词、拍一拍和活跃话题不能绕过 |
| 普通消息参与概率 | 0–100% 滑条；仅 @ 开启时暂停使用该概率，保留其数值 |
| 群聊／私聊回复 | 分别开启或关闭；私聊开启后按直接对话处理 |
| 允许回复的群／私聊名单 | 本人显式填写；新实例默认空名单，不继承现有机器人的名单 |
| 上下文条数 | 0–500；允许聊天中的未触发消息仍进入上下文历史 |
| 人设 | 本人机器人统一角色描述 |
| 语音回复 | 使用已配置的腾讯 TTS；单独检查密钥、资助和额度 |
| 自动语音概率 | 独立的 0–100% 滑条 |
| 音色、语速和音量 | 使用现有音色目录及参数校验 |

这里的语音设置控制语音合成回复，不能据此宣称已经实现实时双向通话。确定性外部付费能力仍通过已有费用保护。

每项设置支持“使用平台默认”，取消后填写本人的覆盖值。缺省或 `null` 恢复继承。默认变更只改变继承项，覆盖项保持。使用 CAS 版本防止旧页面覆盖新设置；离线保存显示“尚未连接”，应用失败明确显示已保存但未生效。

已有公共机器人的初始偏好由当前配置幂等种入；编辑新用户默认值不会自动抹平它的历史分群人设、概率和语音策略。管理员主动保存它的统一机器人偏好后，使用新的统一控制。

## 出资与运行条件

模型模板由服务器保管，只注入明确批准的模型、报价和必要凭据。新 worker 从空白名单和空出资开始，应用本人允许的聊天后才授予模板中有上限的出资。每聊天额度、整个实例总额度、语音额度共同检查；模型重试、工具轮次、后台记忆和 TTS 都需预留、发送、结算或保留未知费用。

示例为实例每日 3 元、单聊天每日 1.5 元、语音另限每日 0.3 元，属于服务器资助上限。偏好覆盖不会暴露供应商密钥或增加资助权限。已有费用的旧账本不能直接启用新总额账本而忽略历史费用；已启用的总额配置也不能被直接移除。

默认容量检查需要至少 1,120,000 KiB 可用内存，再启动一个 QQ；人数名额与实际内存分别检查。资源不足明确拒绝新实例。部署模板和依赖说明见 [broker 部署说明](../../scripts/deploy/HOSTED_QQAGENT.md)。平台设置 `QQ_AGENT_HOSTED_CLIENT_CONFIG` 指向私有客户端 JSON（baseUrl、secret、maxBots），公开代理只开放账号平台接口，不开放 broker 或 worker 端口。

## 模型服务切换暂停

模型服务切换期间可将 `productionBudget.platformSuspended` 设为 true；平台出资在统一出口拒绝新调用，用户自带 Key 不借用平台凭据。`platform.apiAccessPending` 保证应用重启后保留 AI 暂停状态。供应商返回权限或套餐错误时保留暂停，不能自动切回旧平台 Key。恢复前须核实新服务权限、模型、工具及费用回执，再解除暂停。
