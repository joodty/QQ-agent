# 语音用量统计

入口为工作台“语音回复”顶部的“语音用量”。关闭语音或未配置凭据时仍能查询历史；打开页面、切换范围和刷新统计不会调用腾讯云、发送 QQ、清理未知费用或修改语音设置。

## 查询范围与权限

- 今天、最近 7 / 30 / 90 天；按北京时间的请求创建日归属。接口也支持最多 90 天的明确起止日期。
- 当前群聊或私聊；普通账号另可看自己当前有权管理的聊天合计，管理员可看整个平台合计。
- 同号群聊和私聊分别统计。每次请求重新核验登录与资源授权，撤销后不能继续读取该资源的旧用量。
- 显示每日汇总及各聊天汇总；聊天表最多展示记录数最多的 200 个，合计仍包含全部有权查询的记录。

## 指标的含义

| 指标 | 口径 |
| --- | --- |
| 请求记录 | 已进入主账预留的语音记录；未发出和处理中另列，不把预留都当作已调用腾讯 |
| 已发起 | 主账状态为 dispatched、settled 或 unknown |
| 成功合成 | 已验证并结算音频结果的 settled 记录；不表示 QQ 已送达或手机已播放 |
| 待核对 | unknown，包括被拒绝或请求结果、费用尚未核对的记录；不能直接当作确定成功或确定失败 |
| 请求字符 | 在准备语音报价时保存的字符数；不等于腾讯已计费字符或资源包抵扣量 |
| 成功合成估算 | 主账已结算的标价估算；实际腾讯账单、免费资源包余额和抵扣尚未同步 |
| 尚未结算预留 | reserved、dispatched、unknown 的主账预留；待核对部分另列 |

此前语音记录未保存字符数。旧记录的次数、日期和费用状态保持，不按金额倒推字符，也不显示为已知零；页面显示“已知字符”与“字符不可追溯的记录数”。从本版本起，新语音报价会在原 attribution 中增加 `characters` 和 `voiceType` 数值快照，不记录朗读文本或凭据。

普通引用回复也参与自动语音抽样，选中后用独立语音气泡发送；未选中或确定的合成失败回退文字时保留引用。运行档案另外记录不含正文的语音判断摘要（概率、是否命中、字数、跳过/回退/发送状态），便于区分随机未命中和设置、字数等限制；这些判断不是新增腾讯调用，不能计入合成次数。

语音请求同时受聊天主预算、语音资源补贴和平台语音总额约束。统计只读 `conversation-budget` 的主记录及其语音 attribution，绝不把两个辅助额度 hold 再算成额外两次调用或费用。

## 实现与接口

- `src/speech-usage.js`：每次请求只读打开 `paid-calls.sqlite`，在一致的 SQLite 快照中通过 `json_each` 聚合既有主账文档，不初始化费用守卫、不迁移 schema、不改旧行或 seed。
- `GET /api/platform/speech/usage`：接受 `chatKey?`、`days?`、`from?`、`to?`；拒绝重复、未知、未来日期及过大范围参数。
- 返回 `totals`、`daily`、`conversations`，只含聚合指标与授权聊天键，不返回原始请求 ID、文本、供应商正文、密钥和凭据引用。
- 缺少账本时返回空报表且不创建文件；已有账本格式异常或语音归属资料缺失时返回错误，不伪造零用量。统计错误不阻止打开其他语音设置，刷新统计不清除未保存的音色草稿。

## 验证

```sh
npm run test:speech-usage
npm run test:speech
```

专项包含只读状态不变、辅助账排重、旧字符缺口、跨日、同号群私、资源撤销、真实网关/账号 API、实际 DOM 筛选和错误恢复。万条合成记录验证输出有界；这些隔离测试不消耗真实云额度、不发送 QQ，也不替代真实合成或手机播放验证。实际部署情况以工作记录为准。
