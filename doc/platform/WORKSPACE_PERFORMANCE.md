# 工作台加载与缓存

2026-10-23。本次只优化读取、传输及浏览器缓存，不改变聊天、人设、费用或语音策略。完整旧 API 继续兼容，数据库无迁移。

## 加载路径

旧版管理员语音页依次等待登录、完整概览与凭据、完整语音概览与设置、平台设置、用量，合计七个 GET、五轮等待。完整概览反复携带当前页面不用的人设正文与目录。

新版先确认登录，再取 `GET /api/platform/overview?summary=1` 的当前账号和授权范围。语音页并行读取 `speech/overview?compact=1` 与 `speech/settings?compact=1&chatKey=...`；公共音色目录按内容版本复用。设置就绪即显示，用量随后更新独立区域，不覆盖输入或关闭音色弹窗。凭据仅在 API 配置和费用页读取。首次冷缓存仍需获取目录，不能保证任意网络下瞬间打开。

聊天身份枚举只读取文件名、已有缓存键和档案身份，不为列出群聊加载历史正文。当前档案采用索引元数据查询，与历史分页相互独立；实际聊天继续沿原档案读取。

## 缓存边界

| 数据 | 保存位置与有效期 | 更新方式 |
| --- | --- | --- |
| JS、CSS | 内容摘要版本 URL；浏览器公共 HTTP 缓存一年 | HTML 每次重验证，新发布引用新摘要；错误版本返回 404 |
| HTML | HTTP `no-cache` 与 ETag | 允许重验证，不能长期沿用旧脚本引用 |
| 音色目录 | 内容摘要 URL、HTTP immutable；单个 localStorage 键 | 当前服务器描述符匹配且 SHA-256 校验通过后复用；损坏则重新获取 |
| 凭据的脱敏列表、模板 | 当前页面内存，15 秒 | 区分账号和资源范围；成功写入、显式刷新、身份或授权范围变化时失效 |
| 账号权限、资源列表、预算、当前语音设置 | 每次导航/刷新向服务器读取，HTTP `no-store` | 不把浏览器缓存当权限依据；实际操作继续服务端复核 |
| 人设正文、聊天历史、API Key、密码、Cookie | 不写入新增持久缓存 | 正文按需读取；敏感凭据沿用原服务器存储 |

只持久保存公开目录和原主题偏好。浏览器缺少 Web Crypto 时跳过目录 localStorage，使用 HTTP/内存缓存；容量不足或存储被禁用不阻止页面使用。缓存和旧请求带身份、范围、序号及失效代次隔离，避免切群或换账号后回填旧数据。

GET 最长等待 12 秒，失败显示“重新加载”，由用户主动重试。写入和收费试听不自动重试。401 清除私人界面；当前读取权限 403 清理旧内容；试听预算/冷却等业务 403 保留弹窗并显示原错误，不把业务拒绝误当退出登录。迟到的旧群请求不能清掉新群或向新群节点写历史。

## 传输

应用输出公开资源 ETag，网关只对固定公共静态白名单透传缓存；账号/API 响应仍为 `no-store`。网关按 `Accept-Encoding` 对可压缩文本响应提供 gzip，超过 2 MiB 回到原流，不缓冲 SSE 或音频。HEAD、304、编码协商、弱 ETag 与 Vary 单独验证；付费试听的断开取消继续传播到上游。

语义依据：[HTTP 编码协商](https://www.rfc-editor.org/rfc/rfc9110.html#name-accept-encoding)、[HTTP 缓存](https://www.rfc-editor.org/rfc/rfc9111.html#name-storing-responses-in-caches)。

## 验证与上线

新增专项覆盖实际 app/网关的轻量 API、权限隔离、不读正文、元数据分页、缓存头/压缩、缓存投毒与失效、超时、群切换竞态以及慢用量下的可编辑首屏。DOM 使用 jsdom，不等同真实手机浏览器。

生产发布需要保留当前全部语音概率/开关/补贴与配置、账号会话、人设档案、原始 seed、已结算及 unknown 记录，核验四个已审扩展；不重启 QQ、代理或修改 nginx。实际部署与测量结果见工作记录，不能把本地测试成功当作生产已经切换。
