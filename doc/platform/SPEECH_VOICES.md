# 腾讯云音色选择与试听

工作台“语音回复”中的“选择音色 / 试听”打开一个共用选择窗口。普通账号为已授权的群或本人私聊选择音色，管理员还可设置平台默认音色；两者共用目录、报价、试听和发送能力。

## 音色目录

2026-10-23 核验腾讯官网公开 `DescribeVoices` 目录，共 **60 个唯一音色**：精品 14、大模型 17、超自然 29。ID 集合与[官方基础语音合成音色表](https://cloud.tencent.com/document/product/1073/92668)一致，适用当前使用的 `TextToVoice` 接口。没有把旧网页的回退目录、实时专属音色或复刻声音混入，不能称为“几百个全部已接入”。原先六个音色 ID 全部保留。

支持类别、性别和使用场景筛选，以及名称、声音特点和 ID 搜索。音色卡片显示声音特点、类别和价格；可用键盘、手机单列浏览。选中后点“使用这个音色”只改变表单草稿，再点保存才生效。关闭选择窗口不保存；聊天音色可恢复“沿用平台默认”，不会改变其他群或同号私聊。

目录在 `src/speech-voices.js` 中离线使用，网页打开或机器人启动都不访问目录来源。维护命令：

```sh
node scripts/update-speech-voices.mjs
node scripts/update-speech-voices.mjs --write
```

第一条只预览新增、删除和变化，第二条经来源校验后原子更新。工具只读取固定的[腾讯公开目录入口](https://aistudio.cloud.tencent.com/demo-common/democase/getCommonResult)、官方音色表和发现脚本；不使用 Cookie 或 Key，不执行官网脚本，不调用合成。请求有超时、体积和重定向边界，响应 ID、类别和基础接口支持不一致时拒绝覆盖现有目录。更新后需要审阅、测试、提交和部署，不在生产自动更新。

## 两种试听

**腾讯云免费试听**打开官方体验页。核验时目录中的预置音频都因官方防盗链规则返回 403，不能直接在本站播放。没有伪造 Referer、代理绕过或宣称这些音频可以跨站免费播放。

**合成试听**在本站朗读固定短句“你好呀，我是你的智能聊天伙伴。”；纯英文音色改用“Hi, dear friend”，两者均为 15 个字符。按钮点击前显示当前聊天、每次估算费用与冷却限制；选择更贵音色后，试听按该音色的价格计费。采用当前聊天已保存的语速和音量，不保存草稿、不调用聊天模型、不发送 QQ。

该功能需要当前账号有资源写权限，且平台、聊天、补贴和资金来源均已允许语音。它与正常语音共享聊天主预算、语音补贴、平台总额、80% 停止线、并发与持久冷却；私聊未开语音时不能通过试听绕过。单句上限不足 15 字时不会截断或绕过。开始合成后即使关闭弹窗也可能已产生调用与用量；结果只在原弹窗、原聊天和当前播放版本仍有效时播放。

只有用户点击才会请求试听，一次仅有一个页面试听请求在途。关闭、切音色或切聊天会停止播放并回收音频地址；迟到结果不自动播放。真实断开经网关传播取消，已发出的调用仍保留待核对费用，不自动重试。返回音频前再次验证账号、资源、资金、设置和档案，撤权不会把已发生的合成费用抹掉。

## 价格与历史

| 类别 | 通用语音合成首档标价（元／万字符） | 15 字试听估算（元） |
| --- | ---: | ---: |
| 精品 | 0.3 | 0.00045 |
| 大模型 | 1.2 | 0.0018 |
| 超自然 | 6.5 | 0.00975 |

依据[腾讯计费说明](https://cloud.tencent.com/document/product/1073/34112)，按低用量首档标价保守估算，未同步阶梯折扣、资源包实际抵扣、余额或供应商实收。三类资源包分别适用；拥有一种包不表示其他类别可以用该包抵扣。

报价、预留、账本归属与实际请求使用同一个已校验音色 ID，浏览器和模型不能提交单价。新记录保留音色和字符数，试听用途记为 `preview`，与正常语音一起进入只读用量统计；辅助额度 hold 不重复计次数或费用。旧精品记录、历史字符缺口、unknown 和当日 seed 原样保留，不重价、不补猜字符。统计“成功合成”不保证 QQ 送达或手机播放；本站试听本身不发 QQ。
